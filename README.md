A lightweight, beginner-friendly **Network Scanner & Reconnaissance Tool** written in Python. Designed specifically for **Junior Cyber Security Analysts** and **Penetration Testers** to learn network socket programming, port scanning fundamentals, service banner grabbing, and basic recon automation.

---

## 🌟 Key Features

- 🔍 **Port Scanning**: Quickly scans target IPs or hostnames for open TCP ports.
- 🏷️ **Banner Grabbing**: Connects to open ports to retrieve service banners (headers, software versions, system info).
- ⚡ **Multi-Port Support**: Easily customizable port ranges or preset lists of common ports (HTTP, HTTPS, SSH, FTP, MySQL, etc.).
- 🌐 **DNS Resolution**: Converts domain names (`example.com`) to IP addresses automatically.
- 🚦 **Timeout & Error Handling**: Gracefully handles network timeouts, unresolvable hosts, and user interruptions (`Ctrl+C`).
